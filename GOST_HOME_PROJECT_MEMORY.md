# Gost Home: постоянный контекст проекта

Обновлено: 19 ноября 2026 года. Основа: решения Данила из переписки. Это рабочие предпочтения и требования, а не подтверждение актуальности цен, характеристик объектов или выполнения задач.

## Назначение

Gost Home — проект контента о недвижимости и жизни на Пхукете. Данил отвечает за идеи, сценарии, организацию съёмок, съёмку и монтаж. Цель: 30 Reels и 2 YouTube-выпуска в месяц. Контент должен привлекать широкую аудиторию и переводить интерес к острову в интерес к недвижимости.

Итого 30. Это исходный план, а не фактическая статистика. Юлю размещать примерно каждые три дня, через два других Reels. Совместный ролик Юли с Андреем в распределении считать роликом Юли; присутствие Андрея хранить как дополнительного участника. Отдельный ролик Андрея считать Андрею. Не удваивать количество публикаций из-за нескольких участников. При изменениях плана объяснять причину.

## Правила сценариев

- Сильный короткий массовый хук: понятный широкой аудитории, вызывает любопытство и желание досмотреть.
- В сценариях недвижимости не произносить и не писать название жилого проекта, если Данил явно не изменил это правило для конкретной задачи. Внутренние названия в календаре и базе допустимы.
- Использовать только проверенные факты. Цены, доходность, рассрочку, сроки сдачи и характеристики сверять с актуальными материалами; старые сведения не выдавать за актуальные. Не обещать гарантированную доходность без подтверждения.
- Для Марка текущая установка — без шуток. Ранние юмористические форматы не отменяют этого ограничения.
- Передавать конкретику и атмосферу: материалы, интерьер, ощущение пространства, удобство, природу. Избегать пустых «невероятный», «прекрасный», «самый лучший».
- Соблюдать последовательность уже снятых кадров. Не добавлять действия, которых нет в исходнике.
- Давать готовый текст для озвучки с удобными абзацами для копирования в заметки. Технические пояснения отделять от произносимого текста.
- При запросе произношения писать иностранные названия по-русски так, чтобы ведущая могла прочитать их вслух. Не дублировать лишние заголовки и слово «бичклаб» у каждого пункта.
- Короткий CTA: кодовое слово, переход в профиль или вопрос в комментариях по задаче. Для локаций возможен мягкий переход к недвижимости. Утверждённая формулировка: «Смотри в профиле».
- Если Данил просит точечную правку, сохранять остальной утверждённый текст. Не переписывать его целиком по собственной инициативе.
- Длительность согласовывать по задаче; оценку времени озвучки обозначать как приблизительную.

## Форматы и редакционные решения

### Юля + Андрей

Постановочное реалити с ощущением случайной встречи и скрытой камеры. Юля начинает обзор комплекса, замечает Андрея у бассейна, спрашивает «Вы здесь живёте?» и просит подсказать по квартирам. Короткая чёрно-белая вставка передаёт неловкость знакомства, затем возвращается цвет и начинается экскурсия. Диалог естественный, Юля сама задаёт больше вопросов. В конце — повод для следующей серии: сравнить, найти вариант у пляжа, в спокойном районе, с пятью спальнями или двухэтажный.

### Лиза

Эмоции, атмосфера, личный опыт и движение по локации. Направления: кафе, смотровые, районы, необычные места, недвижимость. Уже обсуждались Най Харн, Раваи, Windmill, мыс Промтеп, Karon Viewpoint, Coconuts Café, TU Bar, Summore Day Cafe, On The Rock Bar & Restaurant. Этот список — история тем, а не доказательство готовности роликов. Для уютных кафе пользователь предпочитает популярную динамичную музыку; для смотровых обсуждался энергичный инструментал без слов.

### Андрей

Короткий вопрос — ясный экспертный ответ, включая съёмку в машине. Темы: ошибки покупателей, сравнение объектов, покупка через агентство, управление квартирой из другой страны, разница цен похожих квартир. Для YouTube обсуждалась тема «Как купить недвижимость на Пхукете и не потерять деньги». Полные материалы YouTube нужно читать из исходных документов: содержание ранее упомянутого PDF здесь не восстановлено.

## Требования к рабочему сайту

Это целевая модель развития. Перед изменениями проверять текущий код и данные, не считать весь список реализованным.

- Связать календарь съёмок, производство контента, согласование Андрея, выплаты и запас готового контента.
- Отдельное пространство «Стратегия» для будущего календаря публикаций: день, основной актёр, дополнительные участники, тема и статус.
- Автоматически считать количество и процент публикаций по основному актёру. Отличать план от факта и дату съёмки от даты публикации.
- Отдельное представление следующих роликов на согласование, чтобы видеть очередь.
- Учесть Higgsfield AI в рабочем процессе; Instagram-интеграция — будущее требование, не подтверждённая подключённая функция.
- Сохранять имеющиеся данные, не подменять их вымышленными съёмками, выплатами или публикациями.
- Дизайн и взаимодействия: понятно, компактно, минимум лишних элементов; детали реализации не выносить в пользовательский интерфейс без необходимости.
- Часовой пояс расписания: Asia/Bangkok, Пхукет.

## Локальный проект

Репозиторий: текущая папка `gost-home`. По README на момент добавления этой памяти существует календарь съёмок с участниками, несколькими проектами и локациями, статусами, подготовкой актёров, заметками, переносами, публичной ссылкой отдельного события и разовым экспортом в календарь. Для точного поведения читать актуальные README и код. Облачные записи и факт публикации сайта по этому файлу определять нельзя.

## Общение и поддержание базы

Обращаться к пользователю: Данил. Писать по-русски, коротко, структурно и без воды. По умолчанию без жирного выделения и длинных тире. Ссылки делать кликабельными. Сначала давать готовый результат.

Новые явные решения Данила имеют приоритет над этой памятью. При изменении постоянных правил обновлять соответствующий раздел и дату, не создавая противоречащих дублей. Не переносить в проект личные сведения, здоровье, покупки и другие темы, не относящиеся к Gost Home. Не превращать идеи в выполненные задачи без проверки.
